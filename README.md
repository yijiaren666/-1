# 周报自动生成器 Demo

本地 demo，用于读取飞书多维表格链接，生成周报统计、图表、工作摘要、长周期任务进度记录和下周计划建议。

## 启动

```powershell
node weekly-report-demo/server.mjs
```

打开：

```text
http://localhost:5177
```

## 功能

- 读取飞书 base 链接中的待办事项。
- 统计选定周内的事项总数、完成数、延期风险和长周期事项。
- 使用图表展示每日事项分布和完成结构。
- 对长周期事项记录进度和说明，保存在本地 `progress.json`。
- 自动生成书面化、精简化的本周摘要和下周计划建议。
